# Kindle Paperwhite 4 ハードウェアガイド

## デバイス開け方

PW4にはビスがなく、プラスチッククリップで固定されています。

1. プラスチック製スパッジャー（ヘラ）を下側の隙間に差し込む
2. 四辺をゆっくり外す（上部とサイドは特に慎重に）
3. バッテリーコネクターを外す（作業前に必須）
4. スクリーンケーブルは非常に繊細なため無理に曲げない

**注意**: 金属製のカードや工具は静電気や傷の原因になるため非推奨。

---

## UARTテストパッド位置

バックカバーを外した後、基板上のバッテリーコネクター付近に3つのテストパッドがあります。

```
バッテリーコネクター
      │
  ┌───┴───┐
  │       │
  ○TP1   ← GND (基板GNDに接続して確認)
  ○TP2   ← TX  (デバイス→ホスト) → アダプターの RX に接続
  ○TP3   ← RX  (ホスト→デバイス) → アダプターの TX に接続
```

### 電気的仕様

| 項目 | 値 |
|------|----|
| 電圧レベル | 3.3V TTL |
| ボーレート | 115200 |
| データビット | 8 |
| パリティ | なし |
| ストップビット | 1 |

**警告**: RS-232アダプター（±12V）は直接接続禁止。必ずUSB-UARTアダプター（CH340、CP2102、FT232等）を使用すること。

---

## 推奨USB-UARTアダプター

| チップ | Linux認識 | 備考 |
|--------|-----------|------|
| CH340G | `/dev/ttyUSB0` | 安価・入手容易 |
| CP2102 | `/dev/ttyUSB0` | 安定性高い |
| FT232R | `/dev/ttyUSB0` | 高品質・高価 |

---

## eMMC情報

| 項目 | 値 |
|------|----|
| チップ | Micron MTFC4GACAJCN (または同等品) |
| 実装 | BGA (基板直付け) |
| 容量 | 4GB (8GB variant あり) |

eMMCはBGA実装のためピンアクセスには専用のホットエア機材が必要です。
UART経由でのリカバリーが強く推奨されます。

## SoC識別

UART起動ログに以下が表示されます:

```
CPU:   Freescale i.MX7D rev1.2
Board: Amazon Kindle PW4
```

または:

```
CPU:   Freescale i.MX6SLL rev1.0
```
